# API Testing với Postman & JSON Server

Bộ kiểm thử API cho ứng dụng quản lý người dùng, sử dụng Postman để kiểm tra mã trạng thái, thời gian phản hồi và cấu trúc JSON Response.

## Hướng dẫn chạy thử:
1. Cài đặt JSON Server: `npm install -g json-server`
2. Khởi động server từ file data: `json-server --watch db_17_Dieu.json`
3. Import file Collection (`.json`) vào Postman và chạy kiểm thử.
